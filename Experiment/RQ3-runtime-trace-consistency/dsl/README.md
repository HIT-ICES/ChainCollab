# B2CDSL reference execution

The [simulator](../scripts/dsl_simulator.py) applies the reference semantics to the path inputs materialized from the [shared logical paths](../cases/). Use [run_exp3.py](../scripts/run_exp3.py) for simulation and [parse_b2c.py](../scripts/parse_b2c.py) for model extraction.

Each case retains the simulator inputs, DSL model, and trace records. The corresponding normalized traces and platform comparisons are under [outputs](../outputs/).
